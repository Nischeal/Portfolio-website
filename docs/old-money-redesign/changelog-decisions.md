# Decisions & Rules Log - Old-Money Minimalist Redesign

This document tracks decisions for transforming the portfolio into an old-money editorial aesthetic with subtle seasonal particle layers and understated personal accents.

---

## 🎯 Global Rules & Constraints

1. **Quiet Luxury & Restraint**:
   - Eliminate heavy neon borders, aggressive box-glows, and overt RPG system windows.
   - Emphasize generous whitespace, editorial typography, hairline borders (`#E7E2D8`), and tactile diffuse shadows.
2. **Personal Identity through Visual Nuance**:
   - Fashion & Tailoring: Clean proportion, editorial cards, subtle pill badges, Swiss horology counters (`01 //`).
   - Seasonality: Subtle HTML5 canvas rendering drifting leaves (Autumn) or soft snow (Winter).
   - Solo Leveling: Discreet easter egg (optional Monarch dark toggle, subtle shadow aura interaction).
   - AI & Code: Real projects (**Clip Cuisine**, **Gym Management System**), clean tech tags, direct GitHub links.
3. **Strict Stack Stability**:
   - Preserve Next.js 15 App Router, React 19, TypeScript strict mode, Tailwind CSS.
4. **Milestone-by-Milestone Execution**:
   - Zero pre-plan edits. One milestone at a time with strict testing and approval checkpoints.

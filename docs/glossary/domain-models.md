# Portfolio Domain Glossary & Concept Models

This document defines key terms, architectural metaphors, and domain models used throughout **The Shadow Academic** portfolio.

---

## 🏛️ Domain Concepts & Mapping

| Concept | Domain Meaning | Portfolio Implementation |
| :--- | :--- | :--- |
| **Editorial Split Hero** | The primary introduction merging tailoring elegance with technical authority. | **Hero Section**: Cormorant Garamond display headline, olive typewriter role rotator, paired with a tailored visual card and live availability status pill. |
| **Seasonal Canvas** | Ambient background layer reflecting the beauty of Autumn and Winter. | `<SeasonalCanvas />`: Zero-dependency HTML5 canvas rendering drifting amber/olive leaves (Autumn) or gentle soft snow (Winter). |
| **Seasonal Toggle** | Discreet control allowing visitors to set their preferred seasonal environment. | `<SeasonToggle />`: Minimalist switch in navbar toggling between `[🍂 Autumn]` and `[❄️ Winter]`. |
| **Monarch Mode** | Secret dark-mode shift revealing subtle Solo Leveling shadow essence. | `<ThemeToggle />`: Switches between Old-Money Warm Linen (Light) and Shadow Monarch Espresso Charcoal (Dark). |
| **Selected Work (Archive)** | Curated showcase of engineering projects. | **Projects Section**: Editorial case cards presenting **Clip Cuisine** and **Gym Management System** with architecture highlights and direct GitHub source links. |
| **Technical Craft & Philosophy** | Categorized summary of engineering proficiencies. | **Craft Section**: Clean minimalist breakdown of AI & Computer Vision, Backend Architecture, Databases, and Modern Web Systems. |
| **Inquiry Conduit** | Direct communication channel for recruiters and engineering collaborators. | **Contact Section**: Minimalist editorial form and direct transmission links. |

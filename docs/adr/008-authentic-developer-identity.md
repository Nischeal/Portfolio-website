# ADR 008: Authentic Developer Identity & Verified Stack Alignment

- **Status**: Accepted
- **Date**: 2026-11-12
- **Deciders**: Nischal Basnet, Principal Architect Agent

---

## 1. Context & Problem Statement
The preliminary hero typewriter roles and bio contained speculative or generic copy ("Crafting AI Vision Pipelines", "Scalable Backend Services") that didn't accurately reflect Nischal's real engineering expertise and day-to-day stack. The user specifically requested that all information on the website must be confirmed directly with them to ensure 100% accuracy.

---

## 2. Decision
1. **Verified Engineering Competencies**:
   - Full-Stack Developer
   - Laravel & Livewire Engineer
   - Backend Systems Architect
   - FastAPI & Python Builder
   - System Design & Database Architecture
2. **Typewriter Headline Phrasing**:
   - Prefix: `Building`
   - Rotating Roles:
     1. `Laravel & Livewire Systems`
     2. `FastAPI & Python Backends`
     3. `Full-Stack Web Applications`
     4. `Scalable System Architectures`
3. **Bio Statement**:
   > *"Full-Stack Developer and Backend Engineer specializing in Laravel, Livewire, and Python (FastAPI). Focused on clean system design, robust database architectures, and scalable web platforms. Rooted in Kathmandu, Nepal."*
4. **Top Kicker**:
   > `● KATHMANDU, NEPAL — FULL-STACK & BACKEND ENGINEER`

---

## 3. Consequences
- **Positive**:
  - The hero copy reflects Nischal's actual technical skillset with precision and authority.
  - Zero speculative or unverified claims.
  - Directly matches his projects: **Gym Management System** (Laravel/PHP/MySQL), **Clip Cuisine** (Python/YOLO/PostgreSQL), and enterprise systems.
